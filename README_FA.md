# آینده‌سازان — نسخه آغازین PWA

## اجرای محلی
برای اجرای درست PWA، پوشه را روی یک میزبان HTTPS منتشر کنید یا در رایانه با یک وب‌سرور محلی اجرا کنید (باز کردن مستقیم فایل index.html برای نصب آفلاین کافی نیست).

## امکانات فعال این نسخه
- رابط فارسی و راست‌چین، واکنش‌گرا
- بازی‌های نمونه حروف، صدا، عدد، شمارش، جمع، تفریق، رنگ، شکل، الگو، مقایسه، حافظه، فصل‌ها، حیوانات، مهارت زندگی و آمادگی مدرسه
- پنج قصه کوتاه همراه پرسش درک مطلب
- بازی ریتم و شمارش «صد دانه یاقوت» با همان بخشی از متن که سفارش‌دهنده ارائه کرده است
- امتیاز یکتا برای هر بازی، ستاره، مرحله‌های ۱۰۰ امتیازی و سابقه محلی
- ذخیره روی دستگاه و پوسته آفلاین PWA

## مواردی که برای انتشار واقعی هنوز باید انجام شوند
این ZIP به‌تنهایی APK امضاشده، سرور آنلاین، فضای ذخیره‌سازی ویدیو یا پنل مدیریت عملیاتی تحویل نمی‌دهد. این موارد نیازمند حساب میزبانی و پیکربندی بیرونی هستند:
1. ساخت پروژه Supabase و واردکردن URL و anon key در `config.js`.
2. فعال‌سازی Auth و ساخت حساب مدیر از داشبورد Supabase (رمز در کد عمومی قرار نگیرد).
3. ساخت جدول‌های `profiles`, `activities`, `progress`, `content`, `events` و تنظیم Row Level Security؛ هر کودک فقط رکوردهای شناسه خودش را ببیند و فقط مدیر مجاز به انتشار/حذف محتوا باشد.
4. ایجاد Storage bucket خصوصی/عمومی کنترل‌شده برای ویدیوها و تصاویر و اعمال سیاست‌های دسترسی.
5. اتصال برنامه به Supabase JS SDK، همگام‌سازی صف آفلاین و حل تعارض؛ در این نسخه پیشرفت روی همان دستگاه ذخیره می‌شود و بین دستگاه‌ها همگام نمی‌شود.
6. تکمیل پنل مدیریت CRUD و آمار، اعتبارسنجی فایل، محدودیت حجم ویدیو و پردازش امن.
7. انتشار روی دامنه HTTPS و ساخت QR از نشانی نهایی.
8. ساخت APK با بسته‌بندی Capacitor/Android Studio، امضای release و بارگذاری APK در فضای ذخیره‌سازی دائمی؛ سپس جایگزینی دکمه دانلود و QR در صفحه اصلی.

## نکته امنیت و حریم خصوصی
از نام واقعی، تاریخ تولد، عکس چهره، نشانی یا اطلاعات حساس کودک استفاده نکنید. شناسه تصادفی/نام مستعار کافی است. رمز مدیر و کلیدهای محرمانه فقط سمت سرور نگهداری شوند.

## محتوای صوتی و ویدیویی
در این نسخه فایل صوتی یا ویدیویی دارای مجوز جاسازی نشده است. بخش آهنگ به‌صورت بازی شمارش و ریتم است. برای پخش کامل آهنگ یا ویدیو باید فایل دارای مجوز را مدیر بارگذاری کند.
